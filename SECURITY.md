# Security Policy

## Supported versions

Spella is an actively developed project with no released versions yet. Security
fixes land on `main`.

| Version | Supported |
|---|---|
| `main` | ✅ |
| Anything else | ❌ |

## Reporting a vulnerability

**Please do not open a public issue for a security vulnerability.**

Report it privately through GitHub:

1. Go to the [Security tab][security] of this repository.
2. Choose **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and the impact you think it has.

[security]: https://github.com/Sthabiso10/Spella/security/advisories/new

You'll get an acknowledgement within **7 days**. If the report is valid, you'll
get an assessment and a rough timeline within **30 days**, and credit in the
advisory and release notes unless you'd rather stay anonymous.

This is a solo-maintained project, not a funded one — there is no bug bounty.

## Scope

Spella is an offline, single-device game. There are no accounts, no server, no
analytics and no payments, so the attack surface is genuinely small. Things
that are in scope:

- Anything exploitable in the handling of the bundled dictionary asset.
- Anything exploitable in the response handling of the definition API
  (`freedictionaryapi.com`) — a malicious or MITM'd response causing a crash,
  injection or data leak.
- Dependency vulnerabilities with a demonstrable path to impact in this app.
- Android or iOS build configuration that weakens the app's security posture.

Out of scope:

- Cheating at the game, manipulating local scores, coins, gems or XP. All
  progression is local, unauthenticated and by design trivially editable by the
  device owner. It isn't a security boundary and isn't treated as one.
- Vulnerabilities in `freedictionaryapi.com` itself — report those upstream.
- Reports generated by an automated scanner with no demonstrated impact.

## What Spella sends over the network

Spella contacts exactly two hosts, and transmits no player data to either:

| Host | Why | What is sent |
|---|---|---|
| `fonts.google.com` | Downloads Plus Jakarta Sans on first run (via `google_fonts`) | A standard font request |
| `freedictionaryapi.com` | Definition shown in the round recap | The single English word just played |

No analytics, no telemetry, no ads, no crash reporting, no accounts. The
Android manifest requests `INTERNET` and no other permission. Everything else —
the rules engine, the 315k-word dictionary, scoring, the bot — runs entirely on
device.

See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for the full dependency
and data provenance list.
